FAQ

How does the interaction work?

Each interaction follows the same basic JavaScript flow: user input, processing, state change and visible DOM output.

DOM manipulation means using JavaScript to read, change, create or remove elements from the webpage.

State is data that represents the current condition of an interactive component, such as the counter value or whether dark mode is active.

Event listeners allow JavaScript to react when users click, focus, type, resize or perform other actions.

This demonstration uses JavaScript variables for temporary state and localStorage for the selected theme.
